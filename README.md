# PriorityTask
A visual task board app that combines smart sorting with actionable analytics to help you optimize your workflow.

# Try it out!
Download everything put index and icon should be in a folder called public.

Run npm install express node-fetch body-parser cors dotenv marked

then npm start

open localhost:3000

Make sure you put an openrouter key into .env so you can use the AI aspect.

# Live demo not available please run it on your own computer if you want to try it.
